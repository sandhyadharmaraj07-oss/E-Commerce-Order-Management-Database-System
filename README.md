# E-Commerce Order Management Database System

## Project Overview

This project is developed as part of the Database Management System coursework. The objective is to design and document an E-Commerce Order Management Database System by following the complete database development process, including requirement analysis, entity identification, ER modeling, and relational schema design.

## Project Objectives

- Analyze the requirements of an E-Commerce Order Management System.
- Identify entities, attributes, primary keys, and relationships.
- Design an Entity Relationship (ER) Diagram.
- Convert the ER Diagram into a Relational Schema.
- Organize all project deliverables using GitHub.

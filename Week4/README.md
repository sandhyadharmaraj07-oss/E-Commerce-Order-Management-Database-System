# Week 4: Order Management System & Database Normalization

## Overview
This repository contains the SQL implementation for **Week 4 (Task IV: Order Management System)** of the **E-Commerce Order Management Database System** project. 

The primary focus of this week is on implementing normalized relational tables for orders and order details, populating mock operational data across all core entities, executing transaction updates, and generating key business analytics reports.
